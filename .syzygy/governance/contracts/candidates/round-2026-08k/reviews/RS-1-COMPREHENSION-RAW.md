## Reading notes
This change is the project's first and only authorized OpenSpec specification, itself still a candidate binding nothing until a separate owner adoption act. It specifies one capability of a system called Syzygy: an owner registers a software project by placing a declaration file in a repository, and Syzygy then answers questions about that project's shape with enforced honesty. The 42 requirements fall into seven groups: (1) declaration reading/validation — valid declarations register exactly one project, invalid ones fail by name with no partial registration and no silent repair; (2) consent and coverage — observation happens only under recorded per-(project, repository) consent, every declared repository gets an explicit coverage answer, and partial capture is never dressed as full scope; (3) one fixed human entry file (`.syzygy/intent/OVERVIEW.md`) that routes to authority but is never itself authority; (4) seven independently computed project-shape answers (Registered, Shape present, Human-understandable, Observable, Traceable, Mission-ready, Reconciled) with no combined score/badge/percentage ever, missing evidence rendering `Unknown`-with-reason and demonstrated non-satisfaction rendering `Gap`; (5) every answer explainable via a "Why this answer?" fact set, with humans and machines receiving identical facts; (6) a per-repository four-value (`yes`/`no`/`not-applicable`/`Unknown`) finding on whether the repo's root README links to the entry, which Syzygy may propose but never write; (7) cross-cutting rules on stable opaque identities, a write boundary confined to `openspec/**` and `.syzygy/**`, staleness, unadopted proposals never rendering as current state, and every distinction being machine-readable and non-visual. Deliberate exclusions are explicit: no certification, no health score, no Mission evaluation, no reconciliation computation, no implementation of anything. Each requirement carries a checker-oriented case/observable/oracle/falsifier and an inline warrants block; design.md explains the five structuring decisions; CAPABILITY-COVERAGE places all 26 declared obligations, CONTRACT-COVERAGE disposes all 324 accepted clauses (40 mapped, 284 explicitly "Unknown pending owner-reviewed N/A" rather than silently omitted), and GOVERNING-DEPENDENCIES is the generated union of the inline warrants. The pieces interlock coherently and the comprehension test, in my judgment, succeeds.
