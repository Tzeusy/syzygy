# `openspec/changes/archive/` — intentionally unused

> **Navigation only. Nothing here binds.**

This directory is empty on purpose, and has been since the tree was created.
The OpenSpec convention archives a change once it lands; this project does
not take that step, on the owner's P-55 ruling of 2026-09-07, arm (b). An
adopted change stays where it was authored — its state is named in
[`../../README.md`](../../README.md) and owned by the act recorded there.

Moving an adopted change here would relocate bytes bound by owner act at an
exact digest, so it is an act and not a tidying step.
